## Comment utiliser le code sur Sendwave

Sendwave est une application de transfert d’argent international. Le crédit du filleul intervient sur le premier envoi admissible de l’offre France/EUR.

1. **Ouvrez l’application officielle** et créez un compte si vous êtes un nouvel utilisateur.
2. **Saisissez I4H9G** pendant l’inscription, avant le premier transfert. Selon la version, le champ de saisie se trouve dans le menu du profil. Vérifiez que Sendwave accepte le code.
3. **Préparez votre premier envoi.** Sélectionnez la destination et le mode de réception. Le minimum affiché dans l’offre française documentée est de **50 €**. Consultez les conditions proposées pour votre compte et ce trajet.
4. **Relisez le devis.** Repérez le crédit de **20 €**, le total débité et la somme annoncée au destinataire. Si le crédit attendu manque, vérifiez l’offre avant de payer.
5. **Validez puis suivez le transfert.** La récompense du parrain dépend de la livraison réussie du premier envoi éligible. Le crédit du parrain sert à un transfert ultérieur.

[Consulter les conditions du parrainage Sendwave](https://www.sendwave.com/fr/terms-and-conditions/referral-program)

## Code personnel ou code promo Sendwave ?

Le code bonus **I4H9G** est le code de parrainage personnel de l’éditeur. Un code diffusé lors d’une campagne marketing peut avoir un budget, une échéance et des règles d’utilisation propres. Pour connaître les conditions de votre invitation, ouvrez l’offre de parrainage affichée sur votre compte. [Lire les conditions des codes promotionnels de campagne](https://www.sendwave.com/fr/terms-and-conditions/promo-code-promotion)

## Comparer le coût et la réception

Pour comparer deux devis, choisissez le même pays de départ, la même destination, le même budget total et le même mode de réception. Relevez les frais et le taux de change proposé : celui-ci peut intégrer une marge. Comparez ensuite la somme que votre proche recevra pour le montant effectivement débité, crédit compris.

Le délai annoncé et la façon dont le bénéficiaire pourra récupérer l’argent comptent aussi. Vérifiez ces deux éléments sur le devis de votre trajet. Pour un deuxième envoi, refaites la comparaison au tarif applicable après la première transaction.
