## Comment utiliser le code sur votre premier transfert

1. Ouvrez l’application Taptap Send ou téléchargez-la depuis le [site officiel de Taptap Send](https://www.taptapsend.com/fr).
2. Créez votre compte de nouvel utilisateur et effectuez les vérifications demandées.
3. Préparez l’envoi vers votre destinataire. L’icône cadeau ouvre la rubrique **Parrainages**, où vous pouvez consulter l’offre associée à votre pays d’envoi et à la destination choisie.
4. Sur l’écran de saisie du montant, touchez **« Vous avez un code de parrainage ? »** et entrez **SALAHEDD1933**.
5. Avant de payer, vérifiez que le code a été accepté. Contrôlez le bonus proposé et le montant à envoyer pour atteindre le seuil indiqué.
6. Confirmez l’envoi et suivez sa livraison. Une fois le transfert admissible réalisé, consultez votre solde de récompenses dans l’application. Le délai de crédit peut varier.

## Que reçoit votre destinataire ?

Le devis de l’application indique les frais, le taux de change et la somme nette prévue pour le destinataire. Vérifiez également le mode de réception proposé pour ce trajet. Quand le crédit de parrainage s’applique, le destinataire reçoit davantage pour la même somme débitée de votre moyen de paiement.

Si vous comparez plusieurs services, relevez le montant net pour un même budget, une même destination et un même mode de réception. Retrouvez les conditions du [parrainage Ria](/code-parrainage-ria) et du [parrainage Sendwave](/code-parrainage-sendwave) dans la rubrique [Transfert d’argent](/transfert-argent).
